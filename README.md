# Python Keylogger Lab

A beginner cybersecurity project exploring how keyboard input monitoring works in Python.

## Purpose

This project is created for educational purposes in a controlled environment to understand how keylogging techniques work and how they can be identified from a defensive cybersecurity perspective.

## Learning Objectives

- Learn how Python handles keyboard input
- Understand how keylogging techniques work
- Practice Python file handling and event monitoring
- Learn about the security risks associated with keyloggers
- Explore defensive detection and mitigation techniques

## Technologies

- Python
- pynput
- Visual Studio Code
- Git & GitHub
